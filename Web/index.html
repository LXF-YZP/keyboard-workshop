操作说明

从截图生成配列与定位板

  1. 导入截图：复制截图后按 ⌘V，或点击“粘贴截图”；也可选择图片文件。macOS 按 Control + Shift + Command + 4 可直接截图到剪贴板。优先使用俯视图，避免透视和遮挡。“区域”工具可排除无关界面。
  2. 本机识别：识别轮廓和角度，键位出现后再逐键读取键帽上的字母、数字、常见标点和键名（如 Ctrl、Tab、Space），自动填入“键帽文字”。图标、图案和读不清的键帽保留编号；请叠图检查文字，必要时在右侧手动修改。已校正过的配列可点击“识别键帽文字”，按当前键位补读文字而不重建键位。默认开启“自动校正分体对称”：检测到明确的左右对称键区时，对应键自动处于同一水平线，位置和角度互为镜像，保留各列错位与两侧文字。不对称布局可取消勾选后重新识别。结果是近似配列，漏键可用“描键”补齐，误识别可删除。
  3. 校准与键位编辑：点击“校准”，依次点同一排相邻两个 1U 键的中心，确定图片中的像素键距。键位操作集中在画布上方：“选择”用于点选、拖动和 Shift 多选；“新增”后单击放置 1U 键或拖动描出长键，可连续添加，按 Esc 返回选择。选中键位后可复制或删除，删除也支持 Delete / Backspace；复制、删除后自动回到选择模式，⌘Z 可撤销。右侧只编辑选中键位的尺寸、位置、角度和文字。右侧设置真实毫米键距。透视照片中的距离需要另外校正。把待移动按键直接拖到参考邻键的上、下、左或右侧附近，吸附时会自动采用参考键角度、对齐位置并保持键距，出现深绿色辅助线和角度提示。Option / Alt 临时关闭吸附；底部“邻键吸附”可关闭此功能。
  4. 导出 KLE：完整 JSON 用 Upload JSON 导入 KLE；Raw Data 文本直接粘贴。Decal 仅为示意，不生成轴孔。
  5. 定位板与外壳：在“定位板预览”右侧选择轴孔（MX、开盖缺口、Choc、Alps）、卫星轴、X / Y 键距和板框；可自动布置固定孔，并生成三明治外壳的中框（含 USB 开口）与底板。画布上方切换图层预览。逐键可在“配列校正”中设为不装卫星轴、翻转或旋转轴孔，示意标记可参与板框（例如 TPS65 区域）。
  6. 导出 DXF / SVG：修正所有几何错误后导出当前图层，或勾选合并全部图层。圆角为真实圆弧；切缝补偿只偏移导出刀路，预览按成品尺寸。

分体镜像：在右侧设置对称轴 X，留空按实体键最左与最右中心取中线。点击“选左侧 / 选右侧”或 Shift 多选同侧的一列，再点击“镜像校正另一侧”。对应键的位置、尺寸和角度会镜像校正，保留对侧文字和颜色。仅匹配镜像位置 0.75U 内的明确对应键；成功后固定中线，可清空输入框恢复自动中线。每次校正可用 ⌘Z 撤销。

Shift 单击多选；拖动移动；方向键微调 0.05U，Shift 为 0.25U；⌘Z 撤销；⇧⌘Z 重做；⌘S 保存工程。空白处拖动平移，滚轮缩放。

仅生成平面定位板。曲面键盘需要先确定可展平的分段方案，无法从单张截图还原三维结构。选择“截图键盘轮廓”可先提取截图可见边缘；截图不完整时在画布逐点描绘并闭合，自动结果和手动画线都应按实物核对。

对话式操作

工坊助手：用对话完成设计任务

点击顶部“工坊助手”打开对话面板。修改遵循“预览后应用”：助手先读取工程并生成草稿，你核对画布高亮和差异后再点击应用。助手还可以发起受控的导入、导出和 GitHub 工作流。描述目标和关键参数即可；涉及实体尺寸和接线时，请提供真实数据。输入框按 Enter 发送，Shift+Enter 换行。

首次连接

  1. 打开助手，点击“模型设置”。
  2. 填写服务商提供的 HTTPS Chat Completions 完整地址（以 /chat/completions 结尾）、模型名称和 API Key。
  3. 运行连接测试。通过后即可用中文提问和操作。

API Key 保存在 macOS 钥匙串。服务商会收到你发出的文字以及助手按需读取的工程摘要、设置或日志。没有配置模型也可以照常使用其他软件功能。

读取、检查与导航

  • 读取工程、选中键、键码层、固件、矩阵、GPIO、定位板、开孔和问题清单。
  • 按画面左右侧、视觉行列、键帽文字或当前选择确定目标键；助手会在画布高亮结果。
  • 切换配列、定位板、固件和数据视图，查看指定板层或固件层，缩放到全部内容／选中对象／检查问题。
  • 显示或隐藏网格、参考图，调整参考图透明度。

导航和只读检查不会改动工程。画面左右手与固件左右手是两套信息；视觉行列从 1 开始，矩阵 R/C 从 0 开始。复杂拇指区请查看高亮并手动选择核对。

配列与按键

  • 移动、复制、删除按键；按 X/Y 对齐；整组旋转或镜像校正。
  • 设置宽高、角度、键帽文字、颜色、卫星轴和轴孔旋转。
  • 按当前选择、侧别、行列、键帽文字或分组定位按键。
  • 把当前配列另存为新方案、重命名，或比较和切换历史版本。

配列距离使用 U。移动和改几何不会自动改变键码；复制键会清空矩阵地址，需要按实际接线重新分配。

定位板与加工

  • 设置 MX、Choc、Alps 等轴孔、横纵键距、边距和板框。
  • 设置卫星轴、每片固定孔数量和尺寸，以及三明治中框、底板和加工参数。
  • 新增、调整或删除矩形和圆形开孔；检查加工碰撞和越界问题。
  • 预览定位板／中框／底板，导出当前图层或合并图层的 DXF、SVG。

所有加工尺寸使用 mm。请按机械图提供真实固定孔、USB 和模块开孔位置；TPS65 等示意区域不代表真实开孔尺寸。

固件与键位层

  • 配置 QMK／ZMK、主控、固件名称、USB VID/PID、矩阵行列和二极管方向。
  • 配置左右手、每侧 GPIO、主手，以及分体单线半双工或双线全双工通信。
  • 配置支持的 Azoteq 参数，添加／重命名固件层，批量设置键码、修饰键和 MO／TG／TO 等层动作。
  • 按控制器读取 GPIO 选项并检查缺失接线、引脚冲突、无效键码和层引用。

GPIO 和矩阵映射必须按实际 PCB 接线核对。自动建议仅是草稿；未接线工程可以保留，但不能通过固件导出检查。

截图与识别

  • 从本地文件、剪贴板或聊天输入框导入图片；执行本机按键／键帽文字识别。
  • 框选 ROI 限定识别范围，两点校准图片像素键距，重新识别或补读空白文字。
  • 检查分体对称校正；同图重识别可迁移明确匹配的手动设置。

图片在本机识别，原始截图不会发送给模型。识别结果先作为草稿；补读会保护人工文字和手动第 0 层键码，新图片不会沿用旧接线。

工程文件与导出

  • 导入 KLE 或工程文件；重命名、另存配列、查看和比较本机历史。
  • 导出工程 JSON、KLE、定位板 DXF／SVG 或固件文件夹。
  • 组合配列、定位板和固件修改成为一个提案，并按顺序继续后续导出。

打开和保存通过 macOS 系统窗口选择文件位置。历史记录有容量限制，重要方案请另存独立工程文件作为备份。

编译日志与 GitHub

  • 粘贴编译错误附近的日志，让助手引用具体证据并定位相关设置。
  • 查看受管仓库构建状态、刷新状态、读取日志和下载固件产物。
  • 准备发布当前固件并启动 GitHub Actions 编译。

发布需要 macOS 原生确认，仅允许访问软件管理的固件仓库。构建和当前工程按提交及快照对应；工程修改后，旧结果会标为历史快照。

修改如何生效

  1. 描述目标；需要修改时，助手先读取工程并让软件确定按键。
  2. 软件生成草稿，在画布叠加显示原状态和修改结果，并列出差异、关联影响及校验结果。
  3. 检查高亮和参数后，点击“应用提案”；组合提案整体应用，一次撤销还原。
  4. 导入、导出或发布通过操作卡继续；文件位置由系统窗口选择，GitHub 发布另需原生确认。

可选“允许 3 个以内普通键码直接应用”，只对最多 3 个普通键码修改生效。新增／删除按键、几何、层、矩阵、引脚、主控和定位板修改仍需预览。

当前能力边界

助手不会猜测实物尺寸、PCB 接线或无线硬件可行性，也不会直接刷写键盘、读写任意文件路径或操作任意 GitHub 仓库。目前不支持三维／STEP 建模和无人值守编译修复循环。生成固件仓库不等于已通过真实 Actions 编译或实机验证。
